**b) Client control-tower KPI library (DAX starter set)** — measures on the standard data model (`FactSales`, `FactInventory`, `FactProduction`, `FactCapacity`, `DimItem`, `DimDate`, `DimWorkCenter`):

```DAX
-- Service
OTIF % =
DIVIDE (
    CALCULATE ( COUNTROWS ( FactSales ), FactSales[ShippedOnTime] = 1, FactSales[ShippedInFull] = 1 ),
    COUNTROWS ( FactSales )
)

-- Inventory (snapshot fact: use last date in context)
Inventory Value =
CALCULATE ( SUM ( FactInventory[StockValue] ), LASTDATE ( DimDate[Date] ) )

Avg Daily Demand (90d) =
VAR _end = MAX ( DimDate[Date] )
RETURN
    DIVIDE (
        CALCULATE ( SUM ( FactSales[Qty] ), DATESINPERIOD ( DimDate[Date], _end, -90, DAY ) ),
        90
    )

Days of Cover =
DIVIDE ( CALCULATE ( SUM ( FactInventory[OnHandQty] ), LASTDATE ( DimDate[Date] ) ), [Avg Daily Demand (90d)] )

Excess Inventory Value =
SUMX (
    VALUES ( DimItem[ItemID] ),
    VAR _cover  = [Days of Cover]
    VAR _target = MAX ( DimItem[TargetCoverDays] )
    VAR _value  = [Inventory Value]
    RETURN IF ( _cover > _target * 1.5, _value * ( 1 - DIVIDE ( _target * 1.5, _cover ) ) )
)

-- Capacity (RCCP)
Load Hours = SUM ( FactCapacity[RequiredHours] )
Available Hours = SUM ( FactCapacity[AvailableHours] )
Load % = DIVIDE ( [Load Hours], [Available Hours] )
Overloaded Work Centres =
COUNTROWS ( FILTER ( VALUES ( DimWorkCenter[WorkCenterID] ), [Load %] > 1 ) )

-- Production
Schedule Adherence % =
DIVIDE (
    CALCULATE ( SUM ( FactProduction[ConfirmedQty] ), FactProduction[OnSchedule] = 1 ),
    SUM ( FactProduction[PlannedQty] )
)

-- Forecast (if forecast exists)
Forecast Bias % = DIVIDE ( SUM ( FactSales[ForecastQty] ) - SUM ( FactSales[Qty] ), SUM ( FactSales[Qty] ) )
WMAPE % =
DIVIDE (
    SUMX ( VALUES ( DimItem[ItemID] ), ABS ( CALCULATE ( SUM ( FactSales[ForecastQty] ) - SUM ( FactSales[Qty] ) ) ) ),
    SUM ( FactSales[Qty] )
)
```

**Planning Health Index (proprietary scoring rubric)** — 8 dimensions × 12.5 points: OTIF · Forecast accuracy/bias · Inventory turns vs industry · Excess & obsolete % · Capacity load balance (share of WCs 70–95%) · Schedule adherence · Master-data health (missing lead times, safety stocks, routings) · Planning cycle effort (hours/week). Each scored on a fixed 0/25/50/75/100 band table stored in a `DimScoreBands` table so scores are comparable across clients — this becomes your benchmark database.
